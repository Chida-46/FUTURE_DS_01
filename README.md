
# FUTURE_DS_01

## Sales Performance Dashboard

### Project Overview
This project analyzes business sales data using Microsoft Power BI.

### Objectives
- Analyze revenue trends over time
- Identify top-selling products
- Analyze category and regional performance
- Generate business insights and recommendations

### Tools Used
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

### Dashboard Features
- Total Revenue
- Total Profit
- Total Orders
- Profit Margin
- Monthly Revenue Trend
- Top 10 Products by Revenue
- Revenue by Category
- Revenue by Region
- Interactive Slicers

### Key Insights
- Technology generates the highest category revenue.
- West generates the highest regional revenue.
- Revenue fluctuates across different months.
- Top products contribute significantly to total revenue.

### Recommendations
- Optimize inventory for high-revenue products.
- Investigate lower-performing regions.
- Review category-level profitability.
- Plan inventory based on seasonal trends.
